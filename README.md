# RestAPI-TODO

A simple Todo REST API built with Golang using:

- Gorilla Mux
- CRUD Operations
- REST APIs

---

# Features

- Add Todo
- Get All Todos
- Mark Todo as Completed
- Delete Todo

---

# Tech Stack

- Golang
- Gorilla Mux
- REST API

---

# Install Dependencies

```bash
go get github.com/gorilla/mux

go get github.com/golang-jwt/jwt/v5
